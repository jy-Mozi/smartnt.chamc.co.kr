# 📁 디렉토리 정의서

[🔙 README](../README.md)

## assets
> 이 디렉토리는 이미지, 폰트 및 기타 정적 에셋을 저장하는 곳입니다.

| Name   | Description                  |
|:-------|:-----------------------------|
| fonts  | 아이콘 및 텍스트 폰트 파일이 위치한 디렉토리    |
| images | 전역으로 사용되는 이미지 파일이 위치한 디렉토리   |
| js     | 전역으로 사용되는 js 파일이 위치한 디렉토리    |
| lib    | 외부 라이브러리 및 플러그인 파일이 위치한 디렉토리 |
| styles | 전역으로 사용되는 css 파일이 위치한 디렉토리   |

<br/>

## docs
> 이 디렉토리는 프로젝트 관련 문서 파일을 저장하는 곳입니다.

| Name            | Description            |
|:----------------|:-----------------------|
| components.html | 재사용 가능한 코드 조각을 모아둔 페이지 |
| directories.md  | 디렉토리 정의서 문서 파일         |
| layout.md       | 레이아웃 구조 문서 파일          |
| libraries.md    | 사용 라이브러리 문서 파일         |

<br/>

## pages
> 이 디렉토리는 웹사이트의 각 페이지 및 팝업 파일을 경로별로 저장하는 곳입니다.

| Name          | Description |
|:--------------|:------------|
| index.html    | 페이지 파일      |
| modals/*.html | 팝업 파일       |

<br/>

## root
> 루트 경로에 존재하는 파일에 관한 설명입니다.

| Name              | Description                                            |
|:------------------|:-------------------------------------------------------|
| .gitignore        | Git이 버전 관리를 하지 않을 파일 및 디렉토리를 지정하는 파일                   |
| .prettierrc       | code formatter인 Prettier의 설정 파일                        |
| package.json      | npm 패키지 매니저를 통해 관리되는 프로젝트의 종속성, 스크립트, 메타데이터 등을 포함하는 파일 |
| package-lock.json | npm에서 자동으로 생성되는 파일로, 프로젝트의 정확한 종속성 트리를 보장              |
| README.md         | 프로젝트에 대한 개요, 설치 방법, 사용법 등을 설명하는 문서 파일                  |

<br/>
